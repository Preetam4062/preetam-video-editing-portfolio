## ✨ Features

- 🎬 **Featured Creations** — Showcase of selected video editing projects
- 📱 **Short Form / Reels** — Instagram Reels, Shorts and social media edits
- 🎥 **Long Form Videos** — YouTube and cinematic long-form projects
- 🎞️ **Cinematic Presentation** — Visual storytelling with cinematic thumbnails
- ⚡ **Interactive Portfolio** — Smooth and responsive browsing experience
- 🛠️ **Editing Process** — Overview of the creative workflow
- 💼 **Services** — Video editing services and capabilities
- 💻 **Software Stack** — Tools and software used for editing
- 📩 **Contact Section** — Easy way to connect for collaborations and projects
- 📱 **Responsive Design** — Optimized for desktop, tablet and mobile devices
- 🚀 **Vercel Deployment** — Fast and reliable production deployment
